# ITwZY-MD 

WhatsApp bot with @whiskeysockets/baileys v7

## How to setup project:
### Setup configs

rename .env.example to .env and rename configs/app.yml.bak to configs/app.yml

### Install dependencies 

```bash
pnpm install
```

### Build app
```bash
pnpm run build
```

To run dev:

```bash
pnpm run dev
```

To run production:

```bash
pnpm run start
```
